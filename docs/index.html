What it catches

Comments that narrate the chat or the edit

"as you requested", "now uses", "changed from", "previously", "no longer", "unchanged", "CHANGED:". That history belongs in the commit message.

Comments over budget

By default no more than 2 new comment lines per edit, or 10% of the new code, whichever is more.

Walls of comment

Blocks longer than 3 lines.

What it leaves alone

Lint directives (eslint-disable, # noqa, @ts-expect-error...), normal docstrings and JSDoc, and comments that were already in the file.

Modes: balanced (default), strict (zero new comments), chat (only narration), off. Set one per repo with a .nocomment.json file. 30+ languages.
